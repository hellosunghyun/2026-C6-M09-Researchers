# Pull Request 작성

제목은 `종류/#이슈번호: 작업한 내용`으로 작성한다. 예: `feat/#1: MainView 개발`.

본문은 다음 순서로 작성한다.

1. `## 📄 개요`: 변경 이유와 결과를 설명한다.
2. `## 🔨 작업 내용`: 실제 구현·수정한 내용을 정리한다.
3. `## 🏁 확인 사항`: 코드 컨벤션, 불필요한 로그·주석·import, 변경 기능 동작, 기존 기능 영향, UI 변경 시 화면 첨부 여부를 점검한다.
4. `## 💻 구현 화면`: UI를 구현·변경했다면 해당 iPhone·Apple Watch 스크린샷 또는 GIF를 표로 첨부한다. 해당하지 않으면 이 항목을 삭제한다.
5. `## 👀 리뷰 시 중점적으로 봐주셨으면 하는 부분이 있나요?`: 의견이 필요하거나 집중해서 볼 부분을 적는다.
6. `## 🙋🏻 덧붙일 말`: 테스트 환경, 주의 사항과 전달할 내용을 적는다.

실제 수행한 검증만 완료로 표시하고 미확인 사항을 구분한다. PR 작성은 리뷰 요청·승인·merge 권한을 새로 부여하지 않는다.
