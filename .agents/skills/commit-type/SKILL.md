# 작업 종류 선택

규칙 설명 요청이면 종류의 차이만 설명한다. 종류 선택·검토 요청이면 실제 diff나 작업 범위를 다음 정의와 대조해 결과만 제안한다. 이 Skill은 파일·Git 상태를 변경하지 않는다.

| 종류 | 용도 |
| --- | --- |
| feat | 새로운 기능 추가 |
| fix | 버그 수정 |
| docs | 문서 수정 |
| style | 코드 포맷 등 코드 스타일 변경 |
| design | 사용자 UI 디자인 변경 |
| test | 테스트 코드 작성·리팩토링 |
| refactor | 프로덕션 코드 리팩토링 |
| build | 빌드 파일 수정 |
| ci | CI 설정 수정 |
| perf | 성능 개선 |
| chore | 자잘한 수정이나 빌드 업데이트 |
| rename | 파일·폴더 이름만 변경 |
| remove | 파일만 삭제 |
| add | 패키지·파일 추가 |

코드 포맷과 UI 디자인, 테스트 코드와 프로덕션 코드 리팩토링을 구분한다. 종류를 고르기 위해 작업 범위를 새로 추가하지 않는다.
