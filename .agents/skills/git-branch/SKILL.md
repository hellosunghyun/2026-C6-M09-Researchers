# 브랜치 이름

출처: [Notion 개발 컨벤션의 Branch](https://sassy-cloth-fbe.notion.site/3fa06046c66e804eb90bcfb3d7341498), 2026-10-25 확인.

작업 종류, 실제 Issue 번호, 작업자 이름을 확인하고 `종류/#이슈번호-작업자 이름`으로
작성한다. 원문 예시는 `feat/#1-Theo`다. 예시의 번호와 이름을 그대로 사용하지 않는다.
종류 선택이 필요하면 `../commit-type/SKILL.md`의 원문 유형 목록을 참고한다.

이름을 생성한 뒤 종류·번호·작업자가 실제 작업과 일치하는지 확인한다.
번호나 작업자가 없으면 임의로 만들지 않는다. 원문은 분기 기준 브랜치나 merge 전략을
이 항목에서 정하지 않으므로 이 Skill에 해당 정책을 추가하지 않는다.

규칙 변경 시 Notion 원문과 이 파일을 대조하고 확인 날짜를 갱신한다. 자동 동기화는 없다.
