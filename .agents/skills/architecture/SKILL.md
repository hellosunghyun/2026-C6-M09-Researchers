# 설계·구조 검토

- 규칙 설명 요청: [구조 규칙](references/structure.md)에서 해당 주제만 읽고 설명한다.
- 읽기 전용 검토 요청: 같은 참고 자료와 변경 대상의 실제 Feature·Package.swift·앱 타깃 연결을 대조하고 차이와 영향을 보고한다. 코드를 옮기거나 수정하지 않는다.
- 구현 요청: 명시된 기능·파일 범위에서만 변경하고 상태·Action·데이터 송수신·타깃 연결에 미치는 영향을 확인한다. 구조 검토 요청만으로 패키지를 분리하거나 기존 구조를 일괄 이동하지 않는다.

규칙 설명과 현재 구현 상태를 구분하고, 확인되지 않은 구현·검증 결과를 완료로 표시하지 않는다.
