# 이슈 초안·검토·게시

제목은 `종류: 작업할 내용`으로 작성한다. 예: `feat: MainView 개발`.

- 규칙 설명 요청: 제목 형식과 필요한 양식 항목을 설명한다.
- 초안 작성·검토 요청: 실제 `.github/ISSUE_TEMPLATE/`에서 작업에 맞는 양식을 읽어 필수·선택 항목을 적용한다. 종류 선택이 필요하면 [작업 종류](../commit-type/SKILL.md)를 읽는다. 문제·해야 할 일·확인된 결과로 초안만 작성한다.
- 게시·수정 요청: 사용자가 명시한 저장소·이슈·내용 범위에서만 실행한다. 초안 요청을 게시 허가로 해석하지 않는다.

양식과 라벨 설정을 이 Skill에 복제하지 않는다. 빈 이슈 허용 여부도 실제 `.github/ISSUE_TEMPLATE/config.yml`을 확인한다. 확인되지 않은 기능·재현 결과를 사실처럼 작성하지 않는다.
