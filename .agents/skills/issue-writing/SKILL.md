# Issue 작성

출처: [Notion 개발 컨벤션의 Issue](https://sassy-cloth-fbe.notion.site/3fa06046c66e804eb90bcfb3d7341498), 2026-10-25 확인.
본문 항목은 기존 `.github/ISSUE_TEMPLATE/`가 기준이다.

제목은 `종류: 작업할 내용`으로 작성한다. 원문 예시는 `feat: MainView 개발`이다.
종류가 필요하면 `../commit-type/SKILL.md`의 원문 정의를 참고한다.
본문 작성 시 루트의 `.github/ISSUE_TEMPLATE/`에서 해당 종류의 기존 Form을 읽고
필수 항목과 질문에 실제 작업 내용을 채운다.

제목 형식과 선택한 Form의 필수 항목을 확인한다. 존재하지 않는 템플릿이나 새 필수
항목을 팀 규칙으로 만들지 않는다. Notion에 본문 세부 규칙이 없다는 사실과 기존 Form의
질문을 구분한다. 이 Skill은 Issue 게시나 기존 Issue 변경 권한을 새로 부여하지 않는다.

Notion 또는 Form 변경 시 해당 원문과 이 파일을 대조한다.
