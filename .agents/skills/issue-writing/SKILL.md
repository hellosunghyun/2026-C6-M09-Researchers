# 이슈 작성

제목은 `종류: 작업할 내용`으로 작성한다. 예: `feat: MainView 개발`.

작업에 맞는 본문을 작성한다.

- 새 기능: `✨ 개요`와 `✅ 해야 할 일`은 필수다. `🙏🏻 요구사항`, `🙋🏻 덧붙일 말`은 필요한 경우 작성한다.
- 버그 수정: `🐞 버그 설명`, `📄 버그 재현 방법`, `✅ 기대 동작`은 필수다. 추가 정보는 `🙋🏻 덧붙일 말`에 작성한다.
- 긴급 버그 수정: `🔨 버그 설명`에 문제와 해결 방안을 필수로 작성한다. 추가 정보는 `🙋🏻 덧붙일 말`에 작성한다.
- UI 작업: `✨ 개요`와 `✅ 해야 할 일`은 필수다. 추가 정보는 `🙋🏻 덧붙일 말`에 작성한다.

새 기능·버그·긴급 버그·UI 양식에는 각각 `💻 Feat`, `🐞 Fix`, `🔨 Hotfix`, `🎨 Style` 라벨이 설정되어 있다. 양식에 없는 작업은 빈 이슈로 작성할 수 있다. 양식의 라벨 이름과 제목의 작업 종류를 같은 것으로 단정하지 않는다.

확인되지 않은 기능이나 재현 결과를 사실처럼 작성하지 않는다. 이 Skill은 이슈 게시 권한을 부여하지 않는다.
