# 변경 결과 리뷰

출처: 저장소의 `.github/PULL_REQUEST_TEMPLATE.md`, 2026-10-25 확인.
Notion의 빈 Pull Request 항목에서 가져온 새 규칙이 아니다.

실제 diff와 확인 자료를 다음 기존 템플릿 항목에 대조한다.

- 코드 컨벤션을 준수했는가: 해당 Swift 규칙은 `../code-conventions/SKILL.md` 참조.
- 불필요한 로그·주석·import를 삭제했는가.
- 변경한 기능이 정상 동작하는지 확인했는가.
- 기존 기능에 영향을 주지 않는지 확인했는가.
- UI 구현·변경 시 구현 화면을 첨부했는가.

확인된 결과와 확인하지 못한 항목을 구분해 보고한다. 템플릿은 새 앱 자동 테스트나
리뷰 승인 수를 의무화하지 않는다. 점검 항목을 이유로 작업 범위 밖 코드나 기존 로그를
임의로 수정하지 않는다. PR 본문 작성과 화면 첨부 방식은 `../pull-request/SKILL.md`가 담당한다.

템플릿이 바뀌면 이 목록을 대조한다. 이 Skill은 리뷰 게시나 승인 권한을 새로 부여하지 않는다.
