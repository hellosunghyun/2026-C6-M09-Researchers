# 코드 리뷰

리뷰는 Code Rabbit의 1차 리뷰를 받은 뒤 팀원 최소 2명의 코드 리뷰와 Approve를 거쳐 merge하는 순서다. 이 절차를 확인하는 것과 리뷰 요청·승인·merge를 실행할 권한은 구분한다.

실제 diff와 검증 자료에서 다음을 점검한다.

- 코드 컨벤션을 지켰는가.
- 불필요한 로그·주석·import를 정리했는가.
- 변경 기능이 정상 동작하는지 확인했는가.
- 기존 기능에 미치는 영향을 확인했는가.
- UI를 구현·변경했다면 구현 화면을 첨부했는가.

확인된 결과와 미검증 항목을 구분해서 보고한다. 점검을 이유로 작업 범위 밖 코드나 기존 로그를 임의로 수정하지 않는다. 앱 자동 테스트를 새로 의무화하지 않는다.
