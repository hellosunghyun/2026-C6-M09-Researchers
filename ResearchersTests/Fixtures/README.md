# 파싱 검증 자산

테스트 원본과 라이선스 고지를 먼저 모아둔 PR입니다. 파서와 테스트 코드는 뒤의 PR에서 연결합니다.
앱 런타임에서 자동 다운로드하지 않으며, 테스트는 저장소에 포함한 파일을 사용합니다.

- `RealWorld/`: 형식별 원본 샘플 60개와 대용량 PDF 3개
- `RealWorld/RealWorldManifest.json`: 파일별 출처, 고정 커밋, SHA-256, 라이선스 근거
- `RealWorld/GoldenAssertions.json`: 추출 결과에서 확인할 부분 정답과 구조
- `Licenses/`: 외부 샘플의 라이선스, NOTICE와 원본 README
- 루트의 Office·HWP 파일: 자체 생성한 본문·표·삽입 이미지 샘플

이 PR의 분량이 큰 이유는 테스트 파일과 라이선스 원문 때문입니다.
샘플을 줄 수에 맞추려고 자르거나 재인코딩하지 않았습니다. 검증 로그와 대형 측정 JSON은 포함하지 않습니다.
